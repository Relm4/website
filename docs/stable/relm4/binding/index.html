Easy data bindings between objects.

Particularly, this module provides types and traits that simplify connecting with the primary property of an object. In this context, primary means that the property is the most important and most accessed value stored by the object. Usually, this is very easy to figure out, such as the active property for gtk::ToggleButton. In any case, the primary property type are always documented.

To find out which widgets are currently supported and which property is considered as primary, please look at the list implementers for ConnectBinding. Contributions to add support for more widgets are always welcome.
